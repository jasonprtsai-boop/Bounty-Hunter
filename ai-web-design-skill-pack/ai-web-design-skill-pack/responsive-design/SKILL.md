# Responsive Design
## Purpose
Adapt interaction and information priority across viewport sizes; do not merely shrink desktop UI.
## Check
Mobile, tablet and desktop at minimum, plus content-driven edge widths.
## Decide
What stacks, wraps, collapses, hides, scrolls, becomes a drawer, changes order, or changes interaction model.
## Rules
Keep touch targets usable, prevent horizontal overflow except intentional data regions, preserve primary actions, test long labels/localization, and choose table strategies based on density (scroll, priority columns, alternate cards).
