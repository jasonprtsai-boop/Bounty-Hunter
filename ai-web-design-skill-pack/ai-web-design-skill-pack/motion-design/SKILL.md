# Motion Design
## Purpose
Use motion for comprehension, continuity and feedback—not decoration for its own sake.
## Good uses
State transitions, expand/collapse, navigation continuity, loading/progress, feedback and spatial relationships.
## Defaults
Prefer subtle 150–300ms transitions when no stronger reason exists. Respect `prefers-reduced-motion`.
## Avoid
Constant movement, excessive parallax, bounce everywhere, long blocking entrances, gratuitous scroll effects and animation that delays interaction.
