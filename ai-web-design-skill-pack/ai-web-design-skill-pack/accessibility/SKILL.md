# Accessibility
## Purpose
Target WCAG 2.2 AA where practical and make core flows keyboard/screen-reader usable.
## Validate
Semantic HTML, heading order, keyboard navigation, visible focus, contrast, labels/descriptions, errors, accessible names, landmarks, dialog focus management, reduced motion, touch targets and meaningful alt behavior.
## Rules
Never rely on color alone. Never remove focus indication without an equivalent. Prefer native semantics over unnecessary ARIA. Decorative images should not create noise. Test critical workflows without a mouse.
