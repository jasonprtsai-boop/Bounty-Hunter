# Backend Admin UI
## Purpose
Design efficient operational/admin interfaces where clarity, density, searchability and error prevention outrank decoration.
## Patterns when justified
Sidebar, breadcrumbs, command search, data tables, filters, saved views, pagination, status badges, bulk actions, detail drawer, activity/audit log, permission-aware actions.
## Dashboard rule
Start from operational questions, not a canned layout. Every KPI/chart must support a decision or task.
## Tables
Consider search, sort, filter, pagination, column visibility, row actions, bulk selection and export based on workflow—not by default.
## Safety
Confirm destructive actions, clearly distinguish reversible/irreversible operations, show scope of bulk changes, and never hide permission failures.
