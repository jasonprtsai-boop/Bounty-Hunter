# UI/UX Design
## Purpose
Design clear, efficient, attractive, task-oriented interfaces.
## Priority
User goal > information hierarchy > navigation > interaction clarity > readability > consistency > decoration.
## Before coding each major page
Define primary user, primary task/action, secondary actions, content hierarchy, navigation path, permissions, empty/loading/error/success states, destructive actions, and edge cases.
## UX rules
Minimize unnecessary clicks and recall. Use labels for ambiguous icons. Group long forms. Keep destructive actions explicit. Avoid modal overuse and nested-card clutter. Match density to task frequency.
## Deliverable
A concise page/flow specification sufficient for implementation; wireframes may be textual unless visual output is requested.
