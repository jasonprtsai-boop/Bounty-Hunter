# Design System
## Purpose
Create or maintain `DESIGN.md` as the single visual-language authority.
## Required definitions
- Brand/product personality and audience
- Semantic colors: background, surface, muted, primary, secondary, border, text, success, warning, danger
- Typography: display, h1–h3, body, small, caption, label
- Spacing scale and layout widths
- Radius, border and elevation rules
- Iconography rules
- Motion durations/easing
- Breakpoints and responsive principles
- Component-state conventions
## Rules
Use semantic tokens instead of arbitrary per-component values. Reuse existing tokens. New patterns require a reason. Do not make every section a card.
## Output
Update `DESIGN.md` and ensure implementation consumes the defined tokens.
