# Screenshot to UI
## Purpose
Reconstruct the design logic of a supplied screenshot/reference while producing an original, maintainable implementation.
## Process
1. Confirm the actual screenshot/image is available.
2. Identify page regions and hierarchy.
3. Estimate grid, container width, spacing rhythm and alignment.
4. Extract approximate typography scale, semantic colors, borders, radius and elevation.
5. Map visible patterns to reusable components.
6. Identify responsive assumptions and missing states.
7. Implement using project tokens/components.
8. Render and compare visually; iterate.
## Rules
Treat measurements as estimates unless source specs exist. Do not copy protected brand assets, logos, illustrations or text. Preserve the reference's useful principles, not its identity.
