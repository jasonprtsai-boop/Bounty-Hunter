# Design Audit
## Purpose
Critique a rendered interface as a senior product/UI designer and turn findings into actionable fixes.
## Audit dimensions
Task clarity, IA/navigation, hierarchy, density, typography, spacing, consistency, affordance, forms, states, responsive behavior, accessibility, motion, visual distinctiveness and signs of generic AI-generated styling.
## AI-style smells
Unjustified purple/blue gradients, glass everywhere, giant rounded cards, excessive glow/shadow, floating blobs, oversized hero text, icon-per-sentence, every section boxed, decorative charts, generic four-KPI dashboard.
## Output
List only concrete findings with severity P0/P1/P2, evidence, impact and recommended change. Prioritize structural issues before polish. Re-audit after fixes.
