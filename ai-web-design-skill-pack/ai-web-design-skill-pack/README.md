# AI Web Design & Development Skill Pack

15 modular skills for AI coding agents building polished, usable web products.

## Recommended routing
`web-orchestrator` → research/reference → design system/UX → component research → implementation → responsive/accessibility → visual QA/design audit → performance.

## Installation
Copy the skill folders into the skills directory supported by your agent. Keep the skills modular so the agent loads only what is needed.

## Project-level companion
For medium/large projects, keep a `DESIGN.md` in the project root and treat it as the visual source of truth.
