# Web Performance
## Purpose
Keep production interfaces fast without premature micro-optimization.
## Inspect
Bundle size, client JS, image dimensions/formats, fonts, network requests, caching, lazy loading, rendering, third-party scripts and Core Web Vitals.
## Rules
Measure before major optimization. Avoid duplicate/unused dependencies, unnecessary client components, oversized media, blocking scripts and redundant API calls. Prefer maintainable fixes to tiny theoretical gains.
