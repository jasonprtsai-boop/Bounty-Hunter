## 七、臺中市政府文化局：萬春宮與藍廷珍

資料頁：https://www.culture.taichung.gov.tw/2187646/post

注意：頁面底部標示網站為臺中市政府文化局版權所有，未經允許請勿任意轉載、複製或做商業用途。可作研究參考與連結引用，正式作品建議使用人工摘要。

可用於 RAG 的人工摘要：

萬春宮與藍廷珍、藍興庄、大墩街發展有密切關係。文化局文章說明，藍廷珍在康熙六十年朱一貴事件期間迎請媽祖聖像隨軍渡臺；事件平定後，媽祖信仰與大墩地區開墾、藍興宮建立、萬春宮改稱與後續重建相連。文章也整理日治市街改正導致舊廟遭拆、戰後地方仕紳重建，以及現存文物如龍柱、廟產諭示碑、古鐘、「海晏河清」匾與青斗石獅等。

時間線摘要：

| 年份 | 事件 |
|---|---|
| 1721 | 朱一貴事件，藍廷珍赴臺平亂，迎請媽祖聖像隨行 |
| 1723 | 藍廷珍將媽祖聖像迎至大墩街，創建藍興宮 |
| 1786 | 林爽文事件，藍興宮受損 |
| 1823 | 重建完成並正式改稱萬春宮 |
| 1911 前後 | 日治市街改正，萬春宮因都市計畫與道路開闢遭拆除 |
| 1947 | 戰後地方仕紳發起重建並完成大殿重建 |
| 1958 | 拜殿整修完成 |
| 1971-1975 | 重修天后閣牌樓，逐步形成今日廟貌 |
