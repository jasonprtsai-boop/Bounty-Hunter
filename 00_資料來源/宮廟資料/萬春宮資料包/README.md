# 萬春宮資料包

整理日期：2026-08-05

這包資料用來支援 Temple AI OS 的萬春宮示範場景。資料分成三種等級：

- 可正式使用：政府開放資料、觀光多媒體開放資料。
- 可人工摘要：臺中市文化局、萬春宮官網公開資訊。
- 僅作參考：CRGIS、TRFC 等標示需授權或限研究用途的資料。

建議對外說法：

> 本作品以政府開放資料與觀光開放資料建立萬春宮示範場景，展示任一宮廟如何快速導入 LINE + AI 智慧服務。Demo 活動、報名與 Dashboard 數據為示範資料。

不建議對外說法：

> 萬春宮官方系統、與萬春宮合作開發、萬春宮已授權本系統。

## 檔案說明

- `01_萬春宮基本資料.md`：可直接進資料庫的基本資料。
- `02_資料來源與授權.md`：資料來源、授權、可用範圍與風險。
- `03_圖片連結.md`：圖片連結與使用建議。
- `04_公開活動與服務資訊.md`：官網公開活動整理與 Demo 使用方式。
- `temple_profile.json`：後端或種子資料可用的寺廟基本資料。
