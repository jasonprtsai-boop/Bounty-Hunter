## 5. 對外說法修正

為避免授權與事實風險，送件資料應採用以下說法：

| 避免使用 | 建議改用 |
|---|---|
| 已在萬春宮正式部署上線 | 已完成公開 Demo 部署，並以萬春宮公開資料建立示範場景 |
| 示範合作夥伴：萬春宮 | 示範資料場景：台中萬春宮公開資料 |
| 全功能正式上線實證 | 公開 Demo、測試與部署紀錄支撐產品可行性 |
| 官方萬春宮營運資料 | Demo 活動、報名與 Dashboard 指標為示範資料 |

可保留的強項：

- LINE OA、LIFF、Messaging API、Rich Menu、Flex Message 的整合度。
- AI 回覆安全邊界，不扮演神明、不斷言吉凶、不處理醫療投資等敏感決策。
- 活動報名、進度查詢、Dashboard、客服與通知形成服務閉環。
- 後端測試、前後台建置與公開服務檢查已有證據。

## 6. 最後送件順序

1. 補齊團隊名稱、成員、指導老師與聯絡資訊。
2. 用精美版 PDF 做最後人工逐頁檢查。
3. 上傳 Demo 影片到 YouTube，設定為公開或不公開，不可設定私人。
4. 用未登入或無痕視窗打開 YouTube 連結，確認可播放。
5. 填妥並簽署 4 份文件，放入 `07_比賽交付/簽署文件/`。
6. 最後再跑一次公開服務冒煙檢查。
7. 開官方投件頁，逐項上傳 PDF、貼 YouTube 連結、附簽署文件。
8. 送出後截圖保存收件成功畫面與確認信。
