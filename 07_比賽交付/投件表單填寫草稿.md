## 一句話提案

Temple AI OS 將 LINE 官方帳號、LIFF、Messaging API、Rich Menu、AI 知識問答、活動報名與廟方後台整合成一個宮廟數位服務入口，讓信眾免下載 App 就能完成參拜導覽、活動查詢與服務互動。

## 作品簡介

Temple AI OS 是面向宮廟場域的 AI 服務入口與數位營運平台。信眾可透過 LINE 官方帳號與 Rich Menu 進入服務，在 LINE 內完成文化導覽、參拜流程問答、近期活動查詢、LIFF 活動報名、報名進度查詢、文化抽籤與客服留言。廟方則可透過管理後台查看活動報名、信眾互動、AI 問答熱點與知識缺口，降低人工客服與紙本行政負擔。

本作品以台中萬春宮公開資料建立示範場景，Demo 活動、報名資料與 Dashboard 統計皆為示範資料；若未取得書面授權，不宣稱已正式合作部署或使用官方營運資料。

## 問題與需求

傳統宮廟服務常同時面臨三個問題：第一，年輕信眾與觀光訪客想了解參拜流程、神明故事與活動資訊，但現場資訊分散，容易不知道從何開始。第二，廟方活動報名、名額確認、常見問題回覆與通知多仰賴紙本、電話或人工訊息，重複工作量高且容易出錯。第三，廟方缺少信眾互動數據與問題熱點分析，難以判斷哪些內容需要補充、哪些活動最受關注。

Temple AI OS 的設計重點不是讓 AI 取代信仰詮釋，而是用 AI 協助整理公開資料、引導行政流程與降低服務摩擦，讓信眾更容易接觸文化，也讓管理者更容易營運。

## 解決方案

1. 以 LINE 官方帳號作為信眾入口，降低下載與註冊門檻。
2. 以 Rich Menu 整合參拜導覽、活動中心、文化抽籤、報名進度與客服入口。
3. 以 Messaging API 與 Flex Message 呈現活動卡片、AI 回覆與流程引導。
4. 以 LIFF 提供手機內活動報名、進度查詢與互動頁面。
5. 以 RAG 與安全回覆規則建立宮廟知識問答，避免 AI 扮演神明或斷言吉凶。
6. 以管理後台提供活動、信眾、客服、通知、知識庫與 Dashboard 管理。

## 使用的 LINE 技術

- LINE Official Account：作為主要服務入口。
- Rich Menu：提供 6 格核心功能分流。
- Messaging API：處理 Webhook、對話回覆、Flex Message 與通知流程。
- Flex Message：呈現活動資訊、客服卡片與互動結果。
- LIFF：讓信眾在 LINE 內完成活動報名、查詢與互動畫面。
- LINE Login / LIFF Profile：作為會員識別與個人化服務基礎。

## 使用的 AI 技術

- RAG 知識問答：根據已整理的宮廟公開資料與知識庫回答問題。
- 意圖分流：辨識使用者是在詢問參拜、交通、活動、報名、客服或文化資訊。
- 安全邊界：避免神諭式回答、命運斷言、醫療投資等高風險建議；正式活動資訊以官方公告為準。
- 後台知識缺口整理：協助廟方觀察常見問題與待補內容。

## 商業模式

Temple AI OS 可採 SaaS 訂閱與導入服務並行：中小型宮廟可使用標準化 LINE OA、AI 知識庫與活動報名模組；大型廟宇或年度祭典可採客製導入，包含文化資料數位化、活動高峰期支援、現場 QR / NFC 導覽與進階 Dashboard。未來也可結合周邊商圈、文創貼圖、活動導流與資料分析服務，形成地方創生與宮廟數位營運的雙邊價值。
