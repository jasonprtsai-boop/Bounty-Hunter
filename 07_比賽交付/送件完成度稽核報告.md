## 主要風險

### P1 - YouTube 連結尚未完成

影響：投件表單需要 YouTube Demo Link；只有本機 MP4 不等於已完成送件。

處理：上傳 `07_比賽交付/待上傳送件包/02_Temple_AI_OS_Demo_Final_1080p_送件版.mp4`，設為公開或不公開，將連結填入 `03_YOUTUBE_DEMO_LINK_待填.txt` 與投件表單。

### P1 - 官方簽署文件尚未完成

影響：缺少簽署文件會讓送件包不完整。

處理：從官方投件頁下載最新版文件，完成簽署後放入 `07_比賽交付/待上傳送件包/簽署文件_待補/`。不要自行重打法律文件正文。

### P2 - 官方截止時間與表單欄位需最後確認

影響：不同公告頁面出現日期差異；表單欄位可能以官方投件頁為準。

處理：內部採 2026-09-20 23:59 前完成，投件當天再以官方投件頁確認截止時間與必填欄位。

### P2 - 真實 LINE 手機端流程仍需人工實機驗證

影響：公開服務與 LIFF URL 可開啟，但實機 LINE Rich Menu 點擊、Webhook 回覆與 LIFF Profile 權限需要手機環境驗證。

處理：送件前用實際 LINE 帳號完成加入好友、點 Rich Menu、開 LIFF、送一則訊息、完成一次報名流程。

## 最小剩餘待辦

1. 上傳 Demo 影片到 YouTube，取得可公開觀看的連結。
