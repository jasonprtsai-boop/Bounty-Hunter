# 萬春宮線上服務資料包

整理日期：2026-08-05

這包資料用於萬春宮線上服務流程與後台測試；正式活動、名額與營運資料仍以廟方公告與正式窗口為準。

## 檔案

- `demo_events.json`：活動中心、Flex Message、LIFF 報名頁可用。
- `demo_users.json`：測試使用者與會員分群。
- `demo_registrations.json`：測試報名資料。
- `demo_support_tickets.json`：客服工單測試資料。
- `demo_notification_jobs.json`：推播任務測試資料。
- `demo_dashboard_snapshot.json`：Dashboard 首頁指標。
- `demo_line_messages.json`：Rich Menu、Flex Message 與推播文案。

## 使用原則

- 可呈現完整服務流程：參拜問答、活動卡、LIFF 報名、報名成功、後台統計。
- 對外說明時保留「正式資訊仍以廟方公告為準」的提醒。
- 不放真實個資、不放真實付款帳號、不聲稱為萬春宮正式報名系統。
