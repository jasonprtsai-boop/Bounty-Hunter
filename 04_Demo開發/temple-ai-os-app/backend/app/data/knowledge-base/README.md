# 萬春宮知識庫與固定回覆規則包

整理日期：2026-08-05

這裡放 AI 問答可引用的知識文件。公開 Demo 主聊天路徑採用關鍵詞 FAQ 規則與固定安全回覆；內容以可用開放資料、人工摘要與 Demo 安全規則為主。

## 檔案

- `01_基本問答.md`：地址、主祀神祇、登記、開放資料來源。
- `02_參拜與服務問答.md`：第一次參拜、活動查詢、報名協助。
- `03_歷史文化建築摘要.md`：萬春宮歷史、藍廷珍、藍興宮、建築文物。
- `04_AI安全回覆規則.md`：宗教內容、個資、金流、授權與拒答規則。

## 固定回覆使用建議

- 每段保留來源類型：open_data、tourism_open_data、official_public_reference、human_summary、demo_policy。
- 回答真實資料時使用已審核固定文案，並標示「依公開資料」或「目前公開資料顯示」。
- 回答 Demo 活動時標示「示範資料」。
- 對宗教預測、命運斷言、醫療法律財務建議，使用安全回覆。
