## 一、影片錄製基本規格與準備

1. **解析度與幀率**：1080p (1920×1080)，30fps。
2. **畫面佈局（雙視窗同屏）**：
   - **左半部（佔寬度 40%）**：手機垂直投影視窗（展示 LINE 官方帳號、Rich Menu、LIFF 操作）。
   - **右半部（佔寬度 60%）**：電腦瀏覽器視窗（展示 Admin 後台儀表板、即時報名紀錄更新、活動管理）。
3. **推薦錄影工具**：
   - **OBS Studio**（免費開源，可自由設置手機直式視窗與電腦視窗的子母/並排排版）。
   - 手機投影：可使用 Windows 內建「手機連結」或 scrcpy / LetsView。
4. **背景音樂**：柔和、輕快、現代具有東方禪意的國風科技 Lo-Fi 或輕電子樂（音量設定為旁白的 15%~20%，切忌喧賓奪主）。
5. **預熱提醒**：錄影前 5 分鐘務必先執行 `python scripts/keepalive_ping.py --warm` 確保 Render 後端處於醒著的狀態，避免任何延遲。
